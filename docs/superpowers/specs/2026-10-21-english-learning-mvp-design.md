# 英语学习应用 MVP 设计

- 日期：2026-10-21
- 状态：待用户审阅
- 首版目标：可部署的功能型 MVP
- 技术栈：Spring Boot + Vue 3 + MySQL 8

## 1. 产品目标

为成人英语自学者提供一个以音频课程为核心的移动端学习产品，通过“听、读、写、说”四个环节完成一节课，并帮助用户持续学习和回顾自己的学习情况。

首版免费，不实现购买、支付和财务功能。目标是验证以下闭环：

1. 用户注册并登录。
2. 按分类发现课程，或将课程加入收藏。
3. 进入沉浸式播放器，完成听、读、写、说。
4. 系统记录当前句子、播放位置和各模式进度。
5. 四个模式达到 100% 后进入当前列表的下一门课程。
6. 管理员上传并发布课程，通过看板观察学习数据。

## 2. 目标用户与范围

### 2.1 首版用户

- 成人英语自学者。
- 主要学习口语、听力和职场英语。
- 主要使用手机浏览器。

中小学生用户、家长绑定、教师点评、课程购买和企业培训不在首版范围内。

### 2.2 首版包含

- 手机优先的响应式学习端。
- 共用同一前端工程的响应式管理端 `/admin`。
- 手机号 + 密码注册登录。
- 课程分类浏览。
- 单课时课程的沉浸式播放器。
- 听、读、写、说四种学习模式。
- 课程收藏。
- 当前学习句子和播放位置恢复。
- 周/月学习统计。
- 课程分类、课程、用户和学习数据管理。
- 封面、音频、双语 SRT/VTT 上传。

### 2.3 首版不包含

- 购买、订单、支付、退款和财务模块。
- 课程详情页；点击课程直接进入播放器。
- 评论、评分、分享和消息通知。
- AI 发音评分、语音转写或人工点评。
- 永久保存用户录音。
- 离线下载完整音频。
- 原生 App 和微信小程序。
- 多课程课时结构；每门课程对应一套音频和字幕。

## 4. 核心用户流程

### 4.1 注册与登录

1. 用户使用手机号和密码注册。
2. 手机号必须唯一，密码使用 BCrypt 哈希保存。
3. 首版不接短信验证码，因此不将手机号标记为已验证。
4. 登录成功后返回短期 Access JWT，并通过 HttpOnly Cookie 写入可撤销 Refresh Token。
5. 被禁用用户无法登录或获取媒体地址。

### 4.2 首页与课程切换

1. 首页顶部显示“全部”和后台配置的课程分类。
2. 所有分类后固定显示“我喜欢”Tab。
3. 切换 Tab 后加载对应课程列表。
4. 课程列表只显示已发布课程，按后台排序值升序排列。
5. 点击课程直接进入课程播放器，不经过详情页。
6. 从任一 Tab 进入后，自动切换和上下滑动均以该 Tab 的课程顺序为准。
7. 从“我喜欢”Tab 进入时，下一门和上一门课程也来自收藏列表。

### 4.3 课程播放器

播放器采用全屏、上下分页的沉浸式课程流。

- 背景由课程封面的主色和辅助色生成模糊渐变。
- 顶部展示封面、课程名和分类。
- 中部展示歌词式英中双语字幕，当前句高亮。
- 支持点击任意句子跳转。
- 支持逐句复听、前后 15 秒、播放/暂停和倍速。
- 底部固定“听、读、写、说”四个模式入口。
- 当前播放位置、当前模式和当前句子持续保存。
- 再次进入课程时恢复到上次所在模式、句子和播放位置。

### 4.4 上下切换课程

- 上滑进入当前列表的下一门课程。
- 下滑返回当前列表的上一门课程。
- 手势位移超过 70 像素且以垂直方向为主时触发。
- 正在输入听写、拖动进度或录音时禁用切换，避免误操作。
- 已保存的课程进度在切换后保留。
- 最后一门课程上滑时提示“本列表已学完”，不循环到第一门。
- 第一门课程下滑时提示“已经是第一门课程”。

### 4.5 收藏

- 课程卡片和播放器内均可收藏或取消收藏。
- 点击收藏按钮不能触发进入播放器。
- “我喜欢”只展示已收藏且当前已发布的课程。
- 课程下架后从收藏列表隐藏，重新发布后恢复显示。
- 数据表用 `user_id + course_id` 唯一约束避免重复收藏。

打开收藏课程的顺序以其收藏时间倒序为准。

## 5. 学习模式

### 5.1 听

- 播放完整音频并同步高亮字幕。
- 用户可点击任意句子跳转。
- 某句音频实际播放至少 1 秒后，将该句标记为“已听”。
- 听进度 = 已听句子数 / 当前课程总句子数。

### 5.2 读

- 展示英中双语字幕列表。
- 可点击句子从该处播放。
- 支持显示/隐藏中文，辅助理解检查。
- 某句在阅读模式中可见并停留至少 1 秒后，将该句标记为“已读”。
- 读进度 = 已读句子数 / 当前课程总句子数。

“读”是输入理解训练，不录音；“说”是口头输出训练。

### 5.3 写

- 播放当前句，用户输入听到的英文句子。
- 提交后立即显示正确或错误，并展示正确答案。
- 每句提交非空答案后，将该句标记为“已写”；不要求全部答对。
- 写进度 = 已提交句子数 / 当前课程总句子数。
- 正确率单独统计，不影响课程完成。
- 判分时忽略大小写、首尾空格、连续空格和英文标点。

### 5.4 说

- 先播放原句，再允许用户录音和回放自己的声音。
- 录音只保存在浏览器内存中，不上传服务器。
- 单次录音至少持续 1 秒后，将该句标记为“已说”。
- 说进度 = 已完成录音句子数 / 当前课程总句子数。
- 不做语音识别或自动发音评分。
- 离开课程或刷新页面后录音立即丢弃。

### 5.5 环节完成与自动切课

- 每个模式只有达到自然完成条件后，“完成本环节”按钮才可用。
- 用户需要主动点击按钮，系统才将该模式标记为已确认。
- 四个模式均达到 100% 且均已手动确认后，课程才完成。
- 四个模式完成后，显示“本课已完成，即将进入下一课”。
- 自动切换前显示 3 秒倒计时，并提供取消按钮。
- 下一门课程按当前 Tab 的列表顺序确定。
- 当前列表没有下一门时，提示“本列表已学完”。
- 课程保存 `completed_at`，课程完成状态为四个模式进度全部等于 100% 且四个环节均已手动确认。

## 6. 我的学习

“我的”页面提供“周 / 本月”切换。

- 周视图按周一至周日展示每天是否学习及当日学习时长。
- 月视图使用日历热力图展示学习活跃程度。
- 汇总显示学习天数、学习次数、累计学习时长。
- 同时展示听写正确率和跟读次数。
- “有没有学习”指当天有效学习时长大于 0。

一次学习的统计口径：

- 进入课程并实际学习满 30 秒，记一次学习。
- 在同一课程内切换听、读、写、说，不重复计数。
- 离开课程超过 10 分钟再进入，记下一次学习。
- 时长只累计播放器或练习实际活跃时间。
- 周/月边界统一按 Asia/Shanghai 时区计算。

## 7. 管理端

### 7.1 数据看板

- 用户总数。
- 今日活跃用户和指定日期范围内的活跃用户。
- 课程学习人数。
- 课程完成率。
- 平均学习时长。
- 听写正确率。
- 跟读次数。

### 7.2 分类管理

- 新增、编辑、排序、显示或隐藏分类。
- 分类名称唯一。
- 有关联课程的分类不允许直接删除，只能隐藏。

### 7.3 课程管理

- 按分类、发布状态和关键词筛选。
- 状态包括草稿、已发布、已下架。
- 支持新建、编辑、发布和下架。
- 每门课程有独立封面、音频和双语字幕。
- 课程只允许在封面、音频、字幕均已成功处理且通过校验后发布。
- 已发布课程在没有任何学习记录时可以自由替换媒体。
- 已有学习记录时，修改标题、简介、分类、排序和封面不影响进度。
- 已有学习记录时替换音频或字幕，必须二次确认，并在事务中清除旧字幕句子进度、将课程完成状态重置后重新计算。已有学习次数、学习时长和听写历史保留。

### 7.4 课程上传流程

1. 填写标题、分类、简介、排序。
2. 上传封面：JPG、PNG 或 WebP，最大 5 MB。
3. 上传音频：MP3、M4A 或 AAC，最大 100 MB。
4. 上传字幕：SRT 或 VTT，最大 2 MB。
5. 前端获取预签名地址，直接上传文件到 S3/MinIO。
6. 后端读取字幕并校验时间轴、双语内容和句子顺序。
7. 后端提取封面主色和辅助色，保存播放器主题色。
8. 管理端预览播放器效果。
9. 保存草稿或发布课程。

字幕要求：

- 每个时间轴条目包含两行文本。
- 第一行为英文原句，第二行为中文翻译。
- 开始时间必须小于结束时间。
- 条目按开始时间升序。
- 首版不接受重叠字幕。
- 解析错误需返回文件行号和具体原因。

### 7.5 用户管理

- 按手机号、昵称搜索。
- 查看注册时间、最近学习时间和累计学习时长。
- 支持禁用和恢复账号。
- 禁用后立即无法登录、刷新会话或获取媒体访问地址。
- 不物理删除用户及其学习记录。

首个管理员账号通过一次性初始化命令创建，账号和初始密码从部署环境读取；首次登录后必须修改密码。

## 9. 技术架构

### 9.1 前端

- Vue 3 + TypeScript + Vite。
- Vue Router 区分学习端和管理端路由。
- Pinia 管理登录态、当前课程流和播放器状态。
- 学习端采用手机优先响应式布局；管理端采用桌面优先布局。
- 管理端组件按路由懒加载，避免增大学习端首屏体积。
- PWA 可选安装能力；首版不提供完整音频离线下载。

### 9.2 后端

- Java 21 + Spring Boot。
- REST API，按功能模块组织：认证、用户、分类、课程、学习、统计、文件、管理端。
- Spring Security 负责 JWT 鉴权、刷新会话校验和角色权限。
- 密码使用 BCrypt。
- 使用 Flyway 管理 MySQL 表结构。
- 使用固定结构的统一错误响应和请求 ID。

### 9.3 文件存储

- 开发环境使用 Docker 中的 MinIO。
- 生产环境可使用兼容 S3 的对象存储。
- 客户端通过短时效预签名地址直传。
- 媒体桶默认私有，播放时动态生成短时效访问地址。
- 对象键使用随机标识，不暴露用户原始文件名。

### 9.4 部署

- Docker Compose 编排前端、后端、MySQL、MinIO 和 Nginx。
- Nginx 统一域名和 HTTPS，转发 `/api` 到 Spring Boot。
- 数据库、对象存储和密钥通过环境变量配置。
- 提交 `.env.example`，不提交真实密钥。
- 后端提供 `/health` 和 `/ready` 健康检查。

## 10. 鉴权与安全

- 学习端和管理端共用认证服务，通过角色限制管理端 API。
- 所有权限校验必须在后端执行，不能依赖前端隐藏按钮。
- Refresh Token Cookie 设置 HttpOnly、Secure 和 SameSite；原生客户端可通过 JSON 刷新接口接收刷新令牌。
- 修改数据的请求启用 CSRF 防护。
- 登录接口限制失败频率，避免暴力尝试。
- 音频、封面和字幕通过短时效签名地址访问。
- 上传校验扩展名、MIME、文件大小和实际内容。
- 用户输入按纯文本处理，避免字幕和昵称引发 XSS。
- 服务端日志不得记录密码、Cookie 或完整答案文本。

## 11. 异常处理

- 登录失败统一提示“手机号或密码错误”。
- 禁用账号提示已禁用，并终止现有会话。
- 音频签名地址过期时自动刷新，并恢复当前课程、模式和句子。
- 网络中断显示离线提示；恢复后重试进度上报。
- 进度上报失败时可重试，最终以服务端最后确认的数据为准。
- 字幕解析失败时禁止发布，并显示文件行号和错误原因。
- 上传中断允许重新上传，不产生重复课程记录。
- 麦克风权限被拒绝时显示浏览器设置指引，不影响其他模式。
- 正在输入或录音时禁止上下切换课程。
- 页面切换或请求失败不能删除已有学习记录。

## 12. 测试与验收

### 12.1 自动测试

- 后端单元测试：注册登录、角色权限、字幕解析、收藏、句子进度、课程完成判定。
- 后端集成测试：使用隔离的 MySQL 和 MinIO 验证上传、进度和学习统计。
- 前端组件测试：字幕跳转、倍速、听写、录音状态、收藏、统计视图。
- 端到端测试：
  1. 注册登录。
  2. 分类切换并进入课程。
  3. 完成一句听、读、写、说。
  4. 收藏课程并在“我喜欢”中找到。
  5. 上下滑切换收藏列表课程。
  6. 管理员上传并发布课程。
  7. 学习端看到新课程并产生看板数据。
